# PIX-DT295 の選局（地上波・衛星）

選局の手順はライブラリの [`fe_dt295.c`](../src/lib/fe_dt295.c) に組み込んであり、テーブルファイルは使いません。
残している書き込みは、どれも PIX-DT295 の実機（CFW）で外したりビットを変えたりして、効果を確認したものです。
それぞれ、外すと何が起きたかを下の表にまとめています。

## 地上波

### 接続

| デバイス | アドレス | アクセス方法 |
|---|---|---|
| 地上の復調 IC | 7 bit `0x10` | `[reg 値]` を書く。読むときは `[reg]` を書いてから読む |
| チューナー | 復調 IC の先 | 復調 IC に `[FE C0 reg 値]` を書くと、チューナーの `reg` に届く |

### 初期化（最初に 1 回）

| 書き込み | 確認した結果 |
|---|---|
| 復調 `0x1C` = `0x20` | bit7 と bit6 は 0（どちらかが 1 だとロックしない）。電源投入時は `0x50`。下位 6 bit はどちらでもよい |
| 復調 `0x03` の bit6〜4 を 0 に | どれかが 1 だとロックしない。電源投入時は 0。別のソフトが設定した状態から始める場合に備えて落とす |
| 復調 `0x23` の bit1〜0 を 0 に | どちらかが 1 だとロックしない。電源投入時は `0x4C`（この 2 bit は 0）。理由は上と同じ |
| チューナー `0xFF`（データなし） | リセット。この後チューナーの全レジスタを読むと電源投入時の値に戻っている |
| チューナー `0x05` = `0x1B` | bit6 は 0（1 だとロックしない）、bit4 は 1（0 だとロックしない）、bit3 は 1（0 だと C/N が 1.6〜4.9 dB 落ちる）。電源投入時は `0xDB` |
| チューナー `0x08` = `0x05` | bit2 を 1 にすると C/N が 2〜4.7 dB 上がる。bit0 は 1、bit3 は 0（変えるとロックしない）。電源投入時は `0x01` |
| チューナー `0x03` = `0x01` | bit0 は 1（0 だとロックしない） |

### 選局ごと

| 書き込み | 確認した結果 |
|---|---|
| チューナー `0x0B` = `0x01` | bit0 は 1（0 だとロックしない） |
| チューナー `0x10`・`0x11` | 周波数（1/64 MHz 単位）。`kHz × 64 ÷ 1000` の下位・上位バイト（557,143 kHz → `0x8B49`） |
| チューナー `0x12` = `0x00`、続けて `0x01` | 0 → 1 で新しい周波数を反映させる。`0x00` を抜くと、2 回目の選局で前のチャンネルのままになる。`0x01` を抜くとロックしない |
| 復調 `0x0E` の bit2〜0 を `001` に | ほかの値だと、ロックしても TS が出ない。電源投入時は `111`。上位 5 bit はどちらでもよい |
| 復調 `0x01` = `0x40` | bit6 が 1 だと約 0.65 秒でロック、0 だと 1.1〜1.3 秒かかる。bit7 は 0（1 だとロックしない） |
| 復調 `0x1D` = `0x02` | bit7〜3 は 0（どれかが 1 だと、ロックしても TS が出ない）。電源投入時は `0x55` |

### ロック判定と C/N

- ロック: 復調 `0x80` が `0x00`。ロックするまでに `0x2F` → `0x2E` → `0x04` と変わる
- C/N: 復調 `0x8B`〜`0x8D` の 24 bit。小さいほど良い。dB への換算式はまだありません

### 対応範囲

- 470〜700 MHz（UHF 13〜50 ch）のみ。この範囲では、チューナーのバンド切り替え
  （ページ 1 の `0x31`、ページ 0 の `0x7C`）を書いても書かなくても、C/N と TS は同じでした
- 700 MHz 以上は、受信できるチャンネルが無かったため測っていません。ドライバは受け付けません

### 確認したチャンネル

受信できる UHF のチャンネルでロックしました。録画で確認したのは、強いチャンネルと、ロックする中で最も弱いチャンネルです。
どちらも同期の取り直し・連続性カウンタの飛び・TEI が 0 で、PAT もありました。

## 衛星（BS・CS110）

### 接続

| デバイス | アドレス | アクセス方法 |
|---|---|---|
| 衛星の復調 IC | 7 bit `0x11` | `[reg 値…]` を書く。読むときは `[reg]` を書いてから読む |
| 衛星のチューナー | 衛星の復調 IC の先 | 衛星の復調 IC に `[FE C0 reg 値…]` を書く。値を続けると次のレジスタに進む |

周波数はアンテナから来る IF で指定します（BS1 は 1,049,480 kHz）。LNB への給電はしません。

### 選局ごと: 電源投入時の値に戻すもの

電源投入時の値で正しいものの、別のソフトが変えたまま残すことがあるレジスタです。選局のたびに書き戻します。
右欄は、そのレジスタだけをその値のまま残したときに起きたことです。どの書き込みも必要でした。

| 書き込み | 残っていた値と結果 |
|---|---|
| 復調 `0x17` = `0x00` | `0x01`: ロックしない |
| チューナー `0x11` = `0x00` | `0xC0`: ロックしない |
| チューナー `0x1C` = `0xC0` | `0x00`: ロックしない |
| チューナー `0x29` = `0x71` | `0x70`: ロックしない |
| 復調 `0x0A` = `0xFF` | `0x00`: ロックしない。書いた後に読んでも `0x00` |
| 復調 `0x07` = `0x01` | `0x33`: ロックしても TS が出ない |
| チューナー `0x2A` = `0xBB` | `0xB9`: ロックしない |

### 選局ごと: 選局そのもの

| 書き込み | 確認した結果 |
|---|---|
| 復調 `0x04` = `0x02` | bit1 は 1（0 だと BS の TS が崩れる。CS は変わらない）。ほかのビットは自由 |
| 復調 `0x87` = `0x04` | bit2 は 1（0 だと BS がロックしない。CS はロックするが C/N が 5.8 dB に落ちる）。bit7 と bit5 は 0（1 だとロックしない）。bit3 は 0（1 だと C/N が 0.8〜1.5 dB 落ちる）。bit4 も 0 がよい（1 だと 0.6〜0.9 dB 落ちる）。bit0 は 0（1 だと C/N が 0 と読める） |
| チューナー `0x06`・`0x07` = `0x10`・`0x10` | 16 bit のどこを変えてもロックしない |
| 復調 `0x1E` = `0x00` | bit3 と bit2 は 0（どちらかが 1 だと BS がロックせず、CS は C/N が 5.8 dB に落ちる。電源投入時の `0x14` は bit2 が 1） |
| チューナー `0x00`〜`0x04` | 周波数。計算は下に書く |
| チューナー `0x37` = `0xAC` | bit0 は 0（1 だとロックしない）。bit5 は 1（0 だと BS がロックせず、CS は C/N が 5.3 dB に落ちる）。bit7・bit6 を変えると C/N が 2.2〜4.4 dB、bit4 を変えると 0.5〜1.6 dB 落ちる。bit3〜1 は自由 |
| チューナー `0x05` = `0x80` | bit7 は 1（0 だと BS がロックしない） |
| 地上の復調 `0x0E` の bit2〜0 を `111` に | 地上側が TS の出力線を手放す。どれかが 0 だと、ロックしても TS が出ない。地上波を選局するときに `001` に戻す |
| 復調 `0x1C` = `0x08` | bit7 は 0（1 だとロックしても TS が出ない） |
| 復調 `0x1F` = `0x08` | bit5・4・1・0 は 0（どれかが 1 だとロックしても TS が出ない。電源投入時の `0x15` は bit4 と bit0 が 1） |
| 復調 `0x8E` = `0x02` | bit1 を 1 にすると、ダミーのスロットを落とす。0（電源投入時）だと、CS のトランスポンダーはヌルパケットが 3 割を超え、USB のエンドポイントが受けきれずに連続性カウンタが飛ぶ。1 にするとヌルは 1 割前後に減り、飛びが無くなる。TSID は同じ。BS は変わらない。bit5 と bit2 は効果が見えなかったので 0 |

チューナーの周波数（`0x00`〜`0x04` に 5 バイト続けて書く）:

- MHz = (IF kHz + 500) ÷ 1000（切り捨て）
- IF + 500 kHz が 1,101,000 kHz 未満なら、MHz を 2 倍して `0x04` の bit7 を 1 にする
- `0x00` = MHz ≫ 7、`0x01` = (MHz ≪ 1) の下位 8 bit、`0x02`・`0x03` = 0
- 例: BS1（1,049,480 kHz）→ `10 64 00 00 80`。2 倍する側（BS1・BS3）としない側（BS5 以上）の両方で確認済み

チューナーのバンド切り替え（`0x09`）は、書いても書かなくても全トランスポンダーで C/N の差が 0.3 dB 以内だったので、書いていません。

### TS の選択

BS では 1 つのトランスポンダーに複数の TS が載っています。次の手順を 10 ms ごとに繰り返します。

1. 復調 `0xC3` が `0x00` になるのを待つ。選局直後は 0 以外になり、TS の一覧が読めると `0x00` に戻る。
   `0x01` や `0x10` のときは、一覧が前のトランスポンダーのままのことがあった
2. 復調 `0xCE`〜`0xDD` を読む。TSID が最大 8 個並んでいる（上位バイトが先、`0xFFFF` は空き）。BS1 なら `0x4010`、`0x4011`、`0x4012` の順
3. 選んだ TSID を復調 `0x8F`・`0x90` に書く（一覧が変わったら書き直す）
4. 復調 `0xC5` の bit1 が 1 で、`0xE6`・`0xE7` が選んだ TSID になっていればロック

### ロック判定と C/N

- ロック: 復調 `0xC3` が `0x00`、かつ `0xC5` の bit1 が 1
- C/N: 復調 `0xBC`〜`0xBD` の 16 bit。大きいほど悪い。dB への換算式はまだありません

### 対応範囲と確認したもの

- IF 1,049,000〜2,054,000 kHz（BS1〜CS24）。範囲外は受け付けない
- 受信できる BS・CS110 のトランスポンダーは、すべてロックした
- 録画で確認したのは BS1 の 2 番目の TS（TSID `0x4011`）、BS15（`0x40F1`）、CS2（`0x6020`）。同期の取り直し・連続性カウンタの飛び・TEI はいずれも 0
- 地上 → 衛星 → 地上 → 衛星と切り替えても、どの段階でも崩れは 0
